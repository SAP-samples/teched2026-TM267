**Exercise 3** — Define your Organizational Structure

### Abstract

The **Business Configuration Organizational Structure Agent** helps you build an Enterprise organizational structure proposal based on your migration content from the staging area and SAP Best Practices. It answers org-related Questions and validates selections against the SAP reference org model as well as the selected scope.

The agent is invoked automatically by the Business Configuration Assistant when the user intent is organizational structure-related. You do not call it directly.

> \\\*\\\*Important:\\\*\\\*
> The Organizational Structure Agent will never confirm scope on your behalf. After reviewing the proposal, you must confirm it manually in the \\\*Organizationak Structure\\\* app. Joule always provides a direct navigation link.

Note: A first organizational structure proposal is already pre-loaded to the workspace



1. Switch the Workspace and open worksapce TM267-xx_Migration_Org (XX being your assigned number) 
2. Open the define your organizational Structure app and review the created org structure
3. Go to the Transformation Cockpit and review organizational Structure related Tasks
4. Go to Joule and reinitate the context by reassigning the Workspace with following prompt 
5. Aim to resolve organizational structure issue 
6. Review the results in the Scoping App and Transformation Cockpit




 



**Exercise 3.1** — Analyze Configuration Delta

### Abstract

The **Business Configuration Process Adaptation Agent** analyzes the customer's ECC configuration records against S/4HANA Cloud Public Edition best practices and generates structured, prioritized delta reports. It classifies the discrepancies, assesses the business impact, and recommends a resolution path — reducing weeks of manual spreadsheet analysis to an automated, intelligent assessment.

The Configuration Comparisson app allows a detailed assesment of the configuration Deltas by record and Attribute.

> \*\*Note:\*\*
> The agent analyzes and recommends — it does not apply configuration changes automatically. Configuration adjustments are executed manually in the relevant configuration activity (SSCUI) after reviewing the agent's recommendations. 

</br>

1. Switch the Workspace and open worksapce TM267-xx_Migration_Configuration (XX being your number) 
2. Go to the Transformation Cockpit and review Configuration related Tasks
3. Select configuration issue and navigate to the Comparisson App
4. Review the deviations between ECC data and reference Content

In the Transformation Cockpit, participants can: 

 -Review issues including their severity level 

-Compare legacy configuration vs. Best Practice content side by side in Configuration Compare 

-Track issue status (same status management as org) 

-View related SSCUIs connected to each configuration object 

Note: No live S/4HANA connection — direct navigation into a configuration activity is not possible.
